# Drone Guidance Navigation and Control Simulator

Python implementation of a quadcopter Guidance, Navigation and Control (GNC) simulator.

## Features

- 6-DOF Quadcopter Physics
- PID Flight Controller
- Wind Disturbance Simulation
- Altitude Hold
- Object-Oriented Design
- NumPy + Matplotlib

## Install

pip install -r requirements.txt

## Run

python main.py
